2) 読み込み（HTML）
――――――――――――――――――――
Animateが出力したHTMLを一度だけ編集。
createjsとあなたのドキュメントJSの間あたりでOK。
<!-- 例: index.html の </head> 直前など -->
<script src="typer.js"></script>

※ 効果音を使うなら（どこかで一度）：
<script>
    // mp3のパスとIDは環境に合わせて
    createjs.Sound.registerSound("sounds/type2.mp3", "type2");
</script>

――――――――――――――――――――――――――――――――――――――――
3) 1フレ目のアクション（Animate）
――――――――――――――――――――――――――――――――――――――――
// 舞台初期化 initTyper(this, {
  soundId: "type2",     // 使わなければ null でOKvolume: 0.4,
  autoNext: false,
  nextButtonName: "btnNext" // 各フレームに置くボタンのインスタンス名});

4) デザイナー運用ルール
――――――――――――――――――――――――――――――――――――――――
セリフは見える Text に直接入力、インスタンス名は ty_*
例：ty_main__s1w300（速さ1 / 打ち終わり待機300ms）
フレームごとに演出トゥイーン自由
次へボタンを置くならインスタンス名は btnNext（変更したい場合は options で）
